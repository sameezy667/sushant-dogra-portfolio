# Sushant Dogra — Personal Portfolio

> Senior Software Engineer — On-Device AI & Security  
> Samsung Research · IIT Madras

A production-grade, editorial-style personal portfolio built with React, Bun, Vite, and Tailwind CSS v4, featuring a living 5-stage scroll-transforming ASCII field engine, interactive ANSI block-letter signature, and frosted glass design system.

---

## ⚡ Tech Stack

- **Runtime & Package Manager:** [Bun](https://bun.sh/)
- **Build Tool:** [Vite](https://vitejs.dev/) with `@tailwindcss/vite`
- **Frontend:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Smooth Scrolling:** [Lenis](https://lenis.darkroom.engineering/)
- **Linter:** [Oxlint](https://oxc.rs/)
- **Typography:** Fraunces, JetBrains Mono, Instrument Serif, Newsreader, IBM Plex Mono

---

## ✨ Features

- **5-Stage Living ASCII Engine:** Procedurally generated ambient silicon/circuit simulation transforming across scroll stages (`mainboard` → `neural` → `cipher` → `oscillo` → `surface`).
- **Interactive ANSI Signature Footer:** Real-time character illumination, pointer fire trail, and sweeping scanline across ANSI block typography.
- **Frosted Glass Design System:** Card containers with `backdrop-blur-md` ensure 100% text legibility over dense ASCII field simulations.
- **Hardware-Informed Architecture:** Interactive execution flow depicting NPU tile scheduling, TrustZone TEE, and shared SRAM memory models.

## 🚀 Quick Start

### Prerequisites
- [Bun](https://bun.sh) (v1.2+)

### Development

```bash
# Navigate to portfolio directory
cd portfolio

# Install dependencies
bun install

# Start local dev server
bun dev
```

### Production Build

```bash
cd portfolio
bun run build
bun run preview
```
